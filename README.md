YouTube-Trending-Intelligence

YouTube Trending Video Analytics using Python, SQL, Pandas, and Data Visualization

Project Overview

YouTube Trending Intelligence is a data analytics project that explores trending YouTube videos across the USA, India, and Great Britain.

The project uses Python, SQL, Pandas, and data visualization techniques to analyze video trends, category performance, audience engagement, and country-wise differences.

Objectives

- Analyze trending video records across three countries.
- Identify popular YouTube video categories.
- Calculate average views, likes, dislikes, and comments by category.
- Compare trending video performance across countries.
- Explore video trends over time.
- Present insights through charts and dashboards.

Database Setup

The SQLite database is generated from the cleaned CSV datasets using the Python notebook.

Follow the notebook's database-loading steps before running the SQL analysis queries.

Note: The original and cleaned CSV datasets are not included in this repository because of their large file sizes. The notebook requires the datasets to be available locally to execute the complete analysis.
