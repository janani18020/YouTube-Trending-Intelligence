# YouTube-Trending-Intelligence
Youtube Trending Video Analytics using python, SQL, pandas and Data Visualization
YouTube Trending Intelligence

Project Overview

YouTube Trending Intelligence is a data analytics project that explores trending YouTube videos across the USA, India, and Great Britain. It uses Python, SQL, Pandas, and data visualization techniques to examine video trends and category performance.

Objectives

- Analyze trending video records across three countries.
- Identify popular video categories.
- Calculate average views by category.
- Compare trending video data across countries.
- Present findings through visualizations and a project report.

Technologies Used

- Pandas
